# 音视频通话

会议内“更多”菜单仅保留省流模式开关和设置；隐藏驾驶模式、共享视频、参会者统计及分组讨论室。省流模式启用后，该项用于关闭省流模式。

主页左侧通话按钮默认隐藏，轻点主页显示，再点按钮以外区域隐藏；显示后三秒无触摸操作自动隐藏，离开主页时清除显示状态。原有触摸表情互动保持可用，拖动不切换按钮显示状态，设置抽屉内的操作不会显示通话按钮。

红糖主界面左侧摄像机按钮打开独立的 Jitsi Android SDK 通话页面；菜单“设置 → 音视频通话”保存 HTTPS 服务器地址和房间名称，默认分别为 `https://meet.jpy.wang`、`ht01`。相同服务器和房间的成员可互相通话，不提供自动外呼、联系人通知或来电接听。

点击后显示准备页面，至少等待3秒再加入，可立即取消；首次申请摄像头及麦克风权限，授权后重新等待3秒。还须等待守护采集释放，准备超过20秒提示失败，连接超过45秒终止本次连接。失败后可重试或返回。成功入会后挂断和返回键均确认；等待其他人加入也属于已入会，退出同样确认。支持 SDK 多人视频、成员面板、麦克风/摄像头开关、镜头切换和网格布局。底部工具栏随点击画面显示或隐藏，并沿用 SDK 的自动隐藏行为；顶部挂断按钮保持可见。底部举手图标单独打开表情与举手面板，更多按钮单独打开设置菜单，避免表情面板占用设置菜单高度。

通话期间停止 GuardianService，结束当前对话、关怀和播报，并请求释放本地语音模型；守护采集实际释放后才允许 Jitsi 加入。此期间声音守护、唤醒、陪伴倾听及关怀提醒暂停，错过的提醒不承诺补发。返回主页后等待 SDK 录音释放，再按原设置恢复守护。旧回调及重复点击不得启动第二个通话。退出释放会议视图及音视频资源；SDK 11.6.3 未提供公共 React Native runtime 销毁 API，不能承诺退出后完全回到入会前内存。

SDK 固定11.6.3（其 AAR 声明最低 API 26，与本项目一致），由红糖正式构建依赖，原 App 不引入。当前 Release 未开启代码压缩；启用压缩或升级 SDK 时须重新核对 Jitsi 和 React Native 保留规则、原生库及目标 ABI。服务地址属于用户可编辑配置；不保存通话录音、视频或聊天正文。摄像头、麦克风数据会通过选定的会议服务进行实时通信，服务端自身策略由部署方管理。

红糖固定使用简体中文，不跟随设备的外语设置；本机默认参会名称为“红糖”，未命名远端成员显示为“参会者”。房间标识和其他成员自行设置的名称保留原文。左上角房间及状态提示采用透明背景，文字添加阴影以便在视频上阅读。构建时由 `jitsi-chinese.gradle` 从固定 SDK 生成中文初始化覆盖资产，修正该版原生语言识别和地区码截断问题，并从 `communication/zh-CN.json` 补齐缺漏的中文词条；不提交完整第三方脚本，升级 SDK 若初始化结构变化则构建失败，须重新核对适配。

模拟器可验证界面、状态交接和网络视频；真实可听双向音频、蓝牙/听筒路由、ARM64 性能、低内存设备及多成员长期通话仍须目标设备验收。单次验收记录保存在仓库根目录 evaluation/，历史探针结果不等于正式入口验收。

本次正式入口已在模拟器验证默认房间入会、网页视频接收、三名参与者的网格切换、麦克风静音、配置保存与恢复、准备阶段取消、摄像头权限拒绝、不可达服务器的超时及重试入口，以及确认挂断返回主页和守护采集恢复。未进行物理可听双向音频、会中断网、服务器踢出和长时间内存稳定性验收；已实现相应错误提示及有界连接等待，不将这些分支描述为已验收。入会后左上角仅单行显示“房间名 · 已入会时长”，在线人数和成员状态以 SDK 面板为准。
